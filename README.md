# library99 · 작은 도서관의 5일

Blender로 만든 3D 도서관에서 책 정리와 이용자 응대를 하는 코믹한 사서 생존 게임입니다. 책은 조용하지만 전화와 민원은 조용하지 않습니다.

## 실행

**Code → Download ZIP**으로 내려받고 압축을 푼 다음 **`dist/play.html`을 Chrome 또는 Edge에서 엽니다.** 코드와 모델이 한 파일에 들어 있어 인터넷이나 별도 설치가 필요 없습니다. WebGL2와 하드웨어 가속을 지원하는 브라우저를 사용하세요.

분리된 개발 파일로 실행하려면 Python 3에서 `python serve.py`를 실행합니다. `dist/index.html`은 HTTP 서버/정적 호스팅용입니다.

## v2: 문의와 민원

- 원작 전자 왈츠 BGM: 일부러 조금 삐끗하는 멜로디와 박자의 코믹한 곡. Web Audio로 합성하므로 외부 음원 다운로드가 없습니다. 첫 클릭/키 입력 이후 재생됩니다.
- 데스크 전화기, 전화벨 효과음, 무인 **대출반납기**, 벽면 안내 게시판을 Blender 모델로 추가했습니다. BGM과 효과음은 각각 켜고 끌 수 있습니다.
- 하루는 **4분**, 총 5일입니다. 1분 이후 조기 퇴근도 가능합니다. 미해결 문의는 불만으로 남습니다. 성공 목표를 못 채워도 리뷰/다음 날로 넘어갈 수 있습니다.
- 방문자 또는 전화가 **10–30초 간격**으로 등장합니다. 동시 문의는 **최대 4건**입니다. 데스크 대기줄은 **1–2일차 2명, 3–5일차 3명**까지입니다. 책을 찾는 3초 동안에도 문의 자리를 예약합니다.
- 문의가 시작되면 **30초 안에 해결**해야 합니다. 사서를 찾아오는 이용자, 데스크 대기 이용자, 기기 오류 이용자, 전화가 대상입니다. 이동 중인 이용자는 문의를 시작할 수 있는 위치에 도착한 뒤 제한시간이 시작됩니다. 전화는 벨이 울리는 순간부터 시작합니다.
- 전화/응대/책 관리/게시판 창에서도 시간은 흐릅니다. 도움말, 일시정지, 아침 보고, 하루 리뷰와 다른 탭으로 전환했을 때는 멈춥니다.
- 전화 문의: 운영시간, 대출증, 반납 누락, 행사 신청, 24시간 개방 요구, 주요 시설, 출력 요금, 분실 도서. 오답이나 불친절한 선택지는 이용자의 불만과 다음 날 민원에 반영됩니다.
- 하루 리뷰에는 응대 성공 수, 책 정리, 업무 진행, 실패한 문의와 **실제 플레이어의 대처**가 나옵니다.
- 다음 날 아침 민원은 **전화 / 대면 / 게시판 / 시청 전화 / 국민신문고**로 들어옵니다. 상급자 질책은 약한 서가 안내 민원에 추가됩니다. 형식, 원래 문의, 플레이어의 행동, 무작위 항의 멘트가 함께 표시됩니다.
- “국민의 세금으로 운영되는 주제에”, “내가 세금을 얼마나 내는데”, “높은 사람 나와”, “그러고도 사서냐” 같은 멘트와 익살스러운 변형을 포함했습니다.
- **국민신문고를 받은 날이 3일 이상이면 해고**되어 종료됩니다. 같은 날 여러 건을 받아도 하루로 계산합니다. 5일차에 발생한 민원은 마지막 퇴근 평가에서 접수하여 마지막 날 결과에도 반영합니다.
- 타임아웃·오답·불친절이 별도로 기록됩니다. 단순 서가 안내 오답은 국민신문고로 확대되지 않습니다.

## KDC 책과 따라오는 이용자

- 000 총류, 100 철학, 200 종교, 300 사회과학, 400 자연과학, 500 기술과학, 600 예술, 700 언어, 800 문학, 900 역사: **총 10개 서가**.
- 제공된 KDC 표를 바탕으로 **010–990 세부 분류**를 게임 안 분류표에 표시합니다.
- 책은 `911.125`, `592.495`처럼 **소수점 세 자리의 청구번호**를 가집니다. 책 목록과 바닥 라벨에 표시하며 해당 서가의 세부 분류 구역에 청구번호 순으로 정리합니다. 실제 3D 서가는 100번대별 10개이고, 세부 정리는 게임 상태의 분류/정렬로 관리합니다.
- “뜨개질 책을 찾고 싶어요” 문의에서 **“네, 알겠습니다.”**를 선택하면 이용자가 따라옵니다.
- 해당 서가까지 가서 **E**를 누르면 “이곳의 590 생활과학을 보시면 됩니다” 같은 **정답 1개 + 오답 2개**가 나옵니다. 서가와 세부 분류가 모두 맞아야 정답입니다.
- 안내 후 이용자가 **3초 동안 책을 찾는 동작**을 합니다. 정답이면 “고맙습니다”, 오답이면 “여기에는 그런 책이 없네요”라고 하고 돌아갑니다.
- 오답은 다음 날 **팀장·관장·선임·과장의 주의 / 게시판 불만** 중에서 들어오는 약한 민원으로 제한됩니다. 정답을 선택한 뒤의 3초 연출은 응대 시간 초과로 처리하지 않습니다.

## 조작

| 조작 | 기능 |
| --- | --- |
| WASD / 방향키, 바닥 클릭 | 사서 이동 |
| E | 책·서가·게시판·기기·이용자 상호작용 |
| F | 가까운 데스크 전화 응대 |
| 전화 버튼 | 멀리 있으면 전화기 쪽으로 이동, 가까우면 받기 |
| C | 북카트 연결/놓기 |
| I / 책 목록 클릭 | 책 옮기기 / 정리할 책 선택 |
| Q / R / 오른쪽 드래그 / 휠 | 카메라 회전 / 확대 |
| H / P | 도움말 / 일시정지 |

북카트 최대 12권, 손에 최대 3권을 들 수 있습니다. 북카트에 책을 담은 채 이동하며 바닥 책 수거, 반납함 수거, 서가 정리, 전시, 데스크 대출/반납도 가능합니다.

## 3D 원본과 소스

- `models/library.blend`: 기존 도서관·사서·북카트 원본.
- `models/service-devices.blend`: 추가 전화기·무인 대출반납기·벽 게시판 원본.
- `models/build_scene.py`, `models/build_service_devices.py`: Blender 제작 스크립트.
- `dist/assets/*.glb`: 게임이 사용하는 실제 3D 모델.
- `dist/kdc.js`: KDC 세부 분류, 책/안내 주제, 행사.
- `dist/service.js`: 문의 시간, 등장 제한, 불만, 아침 민원, 해고 규칙.
- `dist/audio.js`: 코믹 BGM과 전화벨 합성.
- `dist/game.js`: 화면, 조작, NPC, 안내 동작, 하루 리뷰.
- `models/game-desktop.png`, `models/preview.png`: v1 도서관 화면과 Blender 렌더 참고 이미지. v2의 전화/게시판 UI가 추가되기 전 이미지입니다.

```sh
npm test
npm run check
blender -b -t 4 -P models/build_service_devices.py
python scripts/package.py
```

핵심 규칙 20개(책/운반/경로 6개, 문의/민원/KDC/행사 14개)와 JavaScript 문법 검사를 통과했습니다. **v2 전체 브라우저 플레이는 검증하지 않았습니다.** 진행 상황은 브라우저에 저장되며 v2 저장 슬롯은 v1과 분리되어 있습니다. 실제 도서관 전산 연결이나 자유 대화 AI는 사용하지 않습니다.
